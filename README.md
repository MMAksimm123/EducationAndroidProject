# EducationAndroidProject

Приложение-каталог: список приложений с рейтингами и детальный экран каждого приложения.
Учебный проект в рамках курса **«Основы Android-разработки» (VK Education)**.

## Возможности

- 📋 Каталог приложений со списком и ключевой информацией по каждому
- ⭐ Отображение рейтингов приложений
- 📄 Детальный экран приложения: описание, оценка, дополнительная информация
- 🌙 Поддержка светлой и тёмной темы
- ⚡ Асинхронная загрузка данных на корутинах (последовательная и параллельная загрузка рейтингов — сравнение подходов и замеры времени)

## Технологический стек

| Слой | Технологии |
| :--- | :--- |
| Язык | Kotlin |
| UI | Jetpack Compose (Material 3) |
| Архитектура | Чистая архитектура: data / domain / presentation |
| Сеть | Retrofit + kotlinx.serialization + OkHttp (логирование) |
| Асинхронность | Kotlin Coroutines (async/await) |
| DI | Hilt (KSP) |
| Навигация | Navigation Compose |
| Загрузка изображений | Coil |

## Структура проекта

```
app/src/main/java/com/example/educationandroidproject/
├── data/           # слой данных: api, dto, mapper, repository
├── domain/         # бизнес-логика: модели и интерфейсы репозиториев
├── di/             # модули Hilt для внедрения зависимостей
├── navigation/     # граф навигации между экранами
└── presentation/   # UI на Compose: каталог, детальный экран (appdetails), тема
```

## Запуск

**Требования:** Android Studio (последняя стабильная версия), JDK 11+, Android SDK 24+.

```bash
git clone https://github.com/MMAksimm123/EducationAndroidProject.git
```

1. Открыть проект в Android Studio.
2. Дождаться синхронизации Gradle.
3. Запустить на эмуляторе или устройстве с Android 7.0+ (minSdk = 24).

Для работы нужно интернет-соединение (загрузка данных из API).


## Что отработано в проекте

- Построение приложения по принципам чистой архитектуры (разделение на data / domain / presentation, mapper между DTO и доменными моделями).
- Внедрение зависимостей через Hilt.
- Работа с сетью: Retrofit + kotlinx.serialization.
- Асинхронная загрузка: сравнение последовательного и параллельного выполнения корутин — параллельная загрузка рейтингов ускорила операцию с ~61,7 с до ~1,6 с на контрольном наборе из 39 запросов.
- Навигация между экранами через Navigation Compose с передачей аргументов.
