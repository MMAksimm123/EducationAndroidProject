# Домашнее задание: Аснхроность и корутины в Kotlin

## Задание 2: Загрузка рейтингов в каталоге приложений

### Результат замеров времени (`measureTimeMillis`)

| Способ загрузки | Фактическое время (Logcat) | Математическое ожидание |
| :--- | :--- | :--- |
| **Последовательно** (Sequential) | **61 744 мс** (~61.7 сек) | ~58 500 мс (39 * 1500 мс) |
| **Параллельно** (Parallel) | **1 572 мс** (~1.6 сек) | ~1 500 мс (время одного запроса) |

### Выводы 
1. **Последовательное выполнение (`for` / `map`)**: Каждый последующий запрос начинается только после полного завершения предыдущего.время выполнения растет линейно в зависисмости от количества элементов.
2. **Параллелное выполнение (`async` + `awaitAll`)**: Все корутины запускаются одновременно в рамках `coroutineScope`. Время выполнения равно времени выполнения **самого долгого** запроса (в данном случае ~1,5 сек). Это дает колоссальный прирост производительности (в 39 раз быстрее).
